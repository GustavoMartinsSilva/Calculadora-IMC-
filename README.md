# Calculadora de IMC

Projeto de uma calculadora de IMC desenvolvida com HTML, CSS e JS.

## Tecnologias usadas:
- HTML5
- CSS3
- JavaScript

## Funcionalidades:
- INserção do nome
- Inserção de altura
- Inserção de Peso
- Cálculo do peso
- Cálculo do IMC
- Classificação do resultado
- Validação dos campos
